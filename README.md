# gyan-all-ml-stats-topics

Notebooks covering ML and statistics topics, mostly A/B testing and feature selection.

## Topics

- **A/B testing** — `complete-guide-to-a-b-testing-a-to-z.ipynb`, `ab_testing_online_store.ipynb`
- **ANOVA / feature selection** — `ANOVA.ipynb`
- **Learning to rank** — `Learn_To_Rank_Concepts.ipynb`
- **ROC & PR curves** — `roc-pr-curves.ipynb`
- **NumPy exercises** — `numpy_exercises.ipynb`

## Data

Datasets used by the notebooks (mainly Cookie Cats and Yandex-style A/B test data) live in `datasets/`.
